Cover Me Up — triad voice-leading

Tue Oct 13 · 6:00–6:30 PM ET 30 min Isbell · triads Follow-up to Oct 3

Coach: Placement said voice-leading and “call 1–3–5 while playing” are both ~1/5. Tonight is only that skill, on a song you already know. Small hand motion + big mouth (say the numbers). Fold ~6–8 min of Time Guru pocket into the drill (speaker/wired — not AirPods).

1. Setup (4 min)

  • Same as Saturday: Drop D + capo you used on Oct 3 (plan default: capo 2 → concert E).
  • Tonight you barely need full open chords — focus on strings 4–3–2 (D–G–B) closed triads.
  • Optional: 2 minutes of Ry Naylor video, then mute and play.
Say out loud: “Concert E (capo 2). I’m voice-leading D–G–Bm–Em shapes with common tones — if a note doesn’t need to move, it doesn’t.”
Pocket cue (Time Guru): Today’s rung = click on 2 and 4 — in a count of 1-2-3-4, the app clicks only on beats 2 and 4 (the backbeat, where a snare usually hits); you play through all four beats. ~60 BPM. Use speaker or wired headphones — not AirPods. Groove target: Cover walkdown D→G→Bm→D on strings 4–3–2 (whole notes for the first loops). Foot tap on quarters (every count: 1, 2, 3, and 4), even when the click is only on 2&4. You’re training the change, not strum fireworks. Optional gap/random mute try if pocket feels solid (app silences the click on purpose so you hear if you rushed when it returns). Voice Memo: record one pass, then listen once — check if you sped up (~6–8 min total).

3. Shapes — strings 4–3–2 (frets from capo)

Read grips as string 4 | string 3 | string 2. These are closed (or nearly) triads.

Primary voice-leading path (verse walk)

D 4-2-3 → G 5-4-3 → Bm 4-4-3 → D 4-2-3

  • D→G: string 2 stays on fret 3 (D common tone).
  • G→Bm: string 2 stays on 3; string 3 stays on 4; only string 4 moves 5→4.
  • Bm→D: string 2 stays; string 4 stays on 4; string 3 moves 4→2.
Furniture rule: Two fingers often don’t move at all between G and Bm. If you lift all three fingers, you just rearranged the living room to change a lightbulb.

Chorus color path

Em 2-0-0 → G 0-0-0 → Bm 4-4-3 → D 4-2-3 (or Em alt 5-4-5 → G 5-4-3 → Bm 4-4-3 → D).

4. Exercises

  1. Static grips (1 pass each) — Hold D 4-2-3, then G 5-4-3, then Bm 4-4-3. Arpeggiate low→high slowly; say 1–3–5 in shape key, then say concert names once.
  2. Interval flash — On Bm grip: “root to b3 is m3.” On D grip: “root to 3 is M3.” Two reps each.
  3. Nearest-inversion loop ×6 — D→G→Bm→D on strings 4–3–2 only. Whole notes. If a finger lifts that didn’t need to, reset.
  4. Chorus loop ×4 — Em→G→Bm→D with the path above. Name Romans: ii–IV–vi–I.
  5. Top-set transfer (optional if time) — Same Romans on strings 3–2–1: find any D, G, Bm, Em triad you already know from CAGED; still prefer common tones.
  6. Song application (10 min) — Play full open Drop-D chords for verse; between strums, insert one triad grip as a fill (especially into Bm and Em). Land melody/hum notes on chord tones from Oct 3 map.
